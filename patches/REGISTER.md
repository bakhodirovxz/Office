# Patch register

Every carried upstream patch has one row (PLAN section 5.3). Parsed by `cargo xt register check`: a patch file without a row,
a row without a file, or an empty cell fails. Categories: `mobile | memory | pdf | brand | i18n | font | ci-fix | parked`.
The "upstream PR" column reads "not sent" while gate decision B-6 stands. Numbering: 0001-0099 functional patches from the
spikes, 0100-0199 the product overlay (applied last), 0900-0999 temporary CI or test fixes.

Measured effects come from `docs/phase0/wordcraft-patches.md`, `gridcraft-templates-spike.md`, `gridcraft-memory-r2.md`
and `gridcraft-pdf-fonts.md`. Where the Phase 0 measurement covers a series, the cell says so.
gridcraft 0001-0019 are the memory rounds 1 and 2; 0020-0022 are the separate pdf-fonts branch, ordered after them.
Both gridcraft series add a module line to `crates/engine/src/lib.rs`; the overlap applied without conflict.
