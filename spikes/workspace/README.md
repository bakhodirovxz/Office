# Spike: one Cargo workspace for wordcraft + gridcraft + deckcraft + pdfcraft

Throwaway Phase 0 spike. Result and analysis: `../../docs/phase0/workspace-conflicts.md`.
Nothing here is compiled; only `cargo metadata`, `cargo tree`, `cargo generate-lockfile` were run.

## Files
- `Cargo.toml` - virtual workspace (members = `src/<app>/crates/*`, `src/<app>/apps/*`; xtask skipped).
- `Cargo.lock` - generated by `cargo generate-lockfile` (fresh resolve, NOT seeded from upstream locks).
- `Cargo.toml.craftlibs-patched` / `Cargo.lock.craftlibs-patched` - variant that redirects every craft-libs git rev to
  `../../upstream/craft-libs` with `[patch."https://github.com/storytold/craft-libs"]`.
- `gen_workspace.py` - regenerates the merged `[workspace.dependencies]` from the four upstream roots
  (needs Python >= 3.11 for `tomllib`; prints every version/feature conflict it resolved). It writes `Cargo.toml.gen`
  with an `@@PATCH@@` placeholder; `patch.toml` is the `[patch]` block to splice in.
- `dups.txt` - `cargo tree -d --workspace -e normal --locked` output for the final lock.
- `src/` - copy of the upstream repos (see below). 83 MB; safe to delete and recreate.

## Why `src/` is a copy
Pointing `members` straight at `../../upstream/<app>/crates/*` fails:
`package ...\upstream\wordcraft\crates\control-key\Cargo.toml is a member of the wrong workspace`
(each crate's nearest ancestor `[workspace]` is the app's own root `Cargo.toml`). Avoiding that without editing
upstream means copying each repo and deleting its root `Cargo.toml` + `Cargo.lock`.

## Reproduce
```powershell
$s='C:\Users\uge226\Desktop\office\upstream'; $d='C:\Users\uge226\Desktop\office\spikes\workspace\src'
foreach($r in 'wordcraft','gridcraft','deckcraft','pdfcraft','craft-libs'){
  robocopy "$s\$r" "$d\$r" /E /XD .git target node_modules /NFL /NDL /NJH /NJS /NP | Out-Null
  Remove-Item "$d\$r\Cargo.toml","$d\$r\Cargo.lock" -Force }
```
```bash
export PATH="$HOME/.cargo/bin:$PATH" CARGO_TARGET_DIR=E:/office-target/spike-workspace
export CARGO_NET_GIT_FETCH_WITH_CLI=true CARGO_HTTP_CHECK_REVOKE=false   # libgit2/schannel fails the revocation check on this box
cd spikes/workspace
cargo metadata --format-version 1 > /dev/null
cargo generate-lockfile
cargo tree -d --workspace -e normal
```
Per-app baseline: `cd upstream/<app> && cargo tree -d --workspace -e normal --locked`.
